Minor Project Report

DocFlow 2.0 • Last edited by Ananya • Version 14 of 14

1. Introduction

This project demonstrates a collaborative document editing platform built on the MERN stack with real-time synchronization via Socket.io. The system supports version control, multi-user collaboration, and AI-assisted writing.

Research Objective: Design and implement a scalable, real-time document collaboration system that integrates AI assistance and Git-like document versioning.

2. System Architecture

The platform uses a microservice-inspired architecture where the React frontend communicates via Socket.io for live changes and REST APIs for persistent operations. typing here...

MongoDB stores document snapshots with delta compression for efficient version storage. Each save creates an immutable snapshot linked in a version graph.

3. Key Features

• Version Control: Git-like branching per document
• Real-time Collaboration: Cursor presence + live deltas via CRDT
• AI Writing Assistant: Powered by integrated LLM API
• Comment Threads: Inline threaded discussions
• Analytics: Word count trends, edit frequency heatmaps
